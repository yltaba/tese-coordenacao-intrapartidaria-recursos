# Arquivo histórico

Esta pasta reúne materiais que não são referenciados pelos capítulos Quarto ativos nem são insumos das figuras atualmente inseridas na tese.

- `rascunhos/`: versões de backup, notas de trabalho e propostas de redação substituídas.

- `temporarios/`: arquivos temporários e mídia auxiliar de sessões anteriores.

Os insumos que ainda sustentam as figuras e a reprodução atual — especialmente `relatorio-consolidado-capitulo-3/`, `resultados-capitulo-3/`, `resultados-exploracao-nucleo/`, `resultados-validacao-top-necr/`, `sensibilidade-top-x/` e `alternativas-top-necr/` — permanecem fora deste arquivo histórico.
